# ChatGPT app

**Status: planned**

The plan is a ChatGPT app that lets people explore Primate Legends from a
chat:

- read about the clans, ranks and the Wiko archipelago
- check a wallet's Legendary Cards, packs, Bounties and daily claim streak
- open the right page of the site to claim or open packs

It will be built on the same read-only vault API as the
[OpenClaw skill](../openclaw/), exposed through an MCP server, so one
integration can serve ChatGPT and other agents that speak MCP.

Nothing here is live yet. Progress is tracked in the
[roadmap](../../docs/roadmap.md).
